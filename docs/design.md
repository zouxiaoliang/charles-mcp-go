# Charles MCP Go 重实现设计

## 已确认的决策

- 使用 Go 重新实现 https://github.com/heizaheiza/Charles-mcp。
- 首期面向本机使用，同时支持 macOS、Windows、Linux。
- 允许重新设计工具接口，以易用性为先，不要求兼容原项目工具接口。
- 用户随后明确要求开始实现并实现所有功能；功能范围为原项目全部 31 项公开工具能力。
- 本机接入采用 stdio；这是开始实现时说明的默认选择。

## 调研基线

- 原项目源码基线：`eb5d0927739ab278cc8903e55e40160efee15c45`。
- 当前工作目录为空，尚无需要迁移的本地实现。

## 实现选择

- 保留 31 个工具名称，参数和结果使用统一模型；查询条件集中在 query 对象中。
- Charles 是独立外部应用，默认连接已有实例；实时默认使用官方 XML 导出，支持原生和 JSON 导出。
- 持久化 SQLite 数据库使用纯 Go 驱动，支持无 CGO 的三平台二进制。
- 实时记录采用稳定身份与更新事件；分页游标不越过未消费的匹配条目。
- 实时会话超时只结束观察并恢复服务开启的录制；历史数据由显式 delete_capture 清理。
- 重放是独立的发送操作；分析工作流默认不发送请求。
- Header 与原始正文保留，预览限制与正文保真状态分别返回。
- 环境恢复通过显式 action 操作；不复刻上游 reset 无条件退出并删除文件的隐式行为。

功能对照与验证依据见 features.md；使用方式见根目录 README.md。
