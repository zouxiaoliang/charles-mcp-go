# Charles MCP Go v1.0.0

Inspect Charles traffic, explain API failures and replay requests from stdio MCP clients such as Claude Desktop and Cursor.

## Highlights

- Live traffic capture through an existing Charles Web Interface, with stable entry IDs, pagination and recording-state restoration.
- Offline XML/JSON and supported native session imports, plus filtering, grouping and login/API workflow analysis.
- Request/response decoding and real HTTP replay with query, header, JSON, form or text mutations.
- Local SQLite persistence for captures, experiments and findings.
- One executable for macOS, Linux and Windows on amd64/arm64. No Python, Node.js or separate database required at runtime.

## Install

Download the file for your OS and CPU from the assets below. On macOS/Linux, add executable permission with `chmod +x <filename>`. Check the original files against `SHA256SUMS`, then run `--version`.

With Go 1.26+:

```sh
go install github.com/zouxiaoliang/charles-mcp-go/cmd/charles-mcp@v1.0.0
```

[Client setup](https://github.com/zouxiaoliang/charles-mcp-go/blob/main/docs/clients.md) · [Reproducible demo](https://github.com/zouxiaoliang/charles-mcp-go/tree/main/examples) · [Three tutorials](https://github.com/zouxiaoliang/charles-mcp-go/tree/main/docs/tutorials)

Live capture requires Charles with its Web Interface enabled. XML/JSON imports work offline; some native session formats need Charles CLI conversion. Replays send real HTTP requests and preserve recorded authentication/cookies. Signature candidate analysis is heuristic.
